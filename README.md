# Inkwell（墨匣）

Inkwell（墨匣）是一个面向长短篇小说创作的本地优先 AI 写作工作台。它把作品管理、纯文本 Markdown 写作、设定资料隔离、伴随式 AI 对话与审阅级改稿整合在同一个桌面工作区中，所有稿件与数据完全留在你自己的电脑里。

## 为什么选择 Inkwell

- **本地优先，数据归你所有**：所有作品、设定、修订历史与对话记录都存储在本地单个 SQLite 数据库和纯文本 Markdown 中，无需云端账号，也不会被厂商绑定，并支持一键生成包含数据库与附件的完整本地 ZIP 备份。
- **作者始终掌握最终落笔权**：AI 提出的任何正文或设定修改都不会静默覆盖你的稿件，而是生成词/句级行内差异进入「待审变更」，由你逐条或批量确认后才会正式写入；若审阅期间你又手动改了正文，冲突检测会保护新稿不被覆盖。
- **防剧透的知识边界**：长篇创作常需要为自己保留未揭晓的伏笔、真凶动机或后文底牌。每条设定都可以直接在列表内一键切换「公开 / 仅全局」；AI 会话默认只读取公开资料，仅当你在需要头脑风暴时手动开启全局视角，隐藏设定才会进入上下文，避免剧透或设定提前泄漏。
- **克制透明，拒绝黑盒编排**：只保留「讨论 / 写作 / 审阅」三种清晰的协作模式，工具边界与系统提示词全部直白可见、随时可改；不内置网文套路模板，也不把写作拆进彼此割裂的流水线。

## 核心工作流

### 1. 书架与作品导入导出

- **多作品书架**：直观展示每部作品的封面、书名、当前总字数、章节数与更新时间，支持直接编辑作品信息、删除作品，或在首页新建与导入作品。
- **双向迁移**：支持将整部作品导出为按分卷/章节/设定分目录组织的 ZIP 压缩包，或单文件 Markdown / TXT 合集；同样支持从结构化包体或文本导入为新作品。

### 2. 分卷章节与独立资料区

- **清晰的左轨结构**：左侧窄导航栏在上方集中承载作品日常创作视图——`书架`、`写作`、`角色`、`背景设定`、`提纲`、`笔记`，下接 `讨论`、`待审变更`、`回收站` 与 `全书搜索`；左下角单独收口 `设置`。
- **高效目录整理**：正文支持分卷与章节管理，资料区按角色、背景设定、提纲、笔记独立分栏并支持单层文件夹；分卷与文件夹均支持名称、一句话副标题、折叠、拖拽排序与跨组拖动。新建章节或设定一键直建并自动聚焦标题，无阻塞弹窗。
- **跨分类多标签页**：工作区顶部标签栏支持同时打开并切换章节、角色、设定、提纲与笔记，点击标签即可同步定位左侧目录；进入作品时自动回到上次编辑的章节。
- **全书检索与误删恢复**：按 `Ctrl+K` 可全局搜索整部作品的正文与设定；误删的章节或设定会先进入「回收站」，支持随时还原或彻底清空。

### 3. 顺手的纯文本 Markdown 写作

- **源码与排版预览无缝切换**：编辑器以纯文本 Markdown 保存，确保修订对比和 AI 改稿干干净净；按 `Ctrl+E`（或点击顶栏切换按钮）即可在源码与渲染预览间切换，预览态下双击正文即可快速回到编辑。
- **常用格式快捷键**：支持 `Ctrl+B`（加粗）、`Ctrl+I`（斜体）与 `Ctrl+U`（下划线），选中文本或直接按键即可快速插入格式标记。
- **显式落库与草稿保护**：点击保存或按 `Ctrl+S` 会将当前改动正式写入数据库并生成修订历史（支持随时回看差异与回溯）；停笔 500ms 后的未保存修改会自动暂存在本地浏览器草稿中，切章或意外关闭前都会提醒保护，绝不静默丢稿。

### 4. 伴随式与全屏 AI 协作

- **双形态共享会话**：写作或查阅设定时，可随时展开右侧伴随对话面板；需要长篇推演或大纲讨论时，可切入全屏「讨论」视图，两种形态共享同一对话流与历史记录。
- **按模式协作**：
  - **讨论**：只读章节正文，专注于剧情推演、人物弧光与设定打磨，可对设定提出待审修改建议，并在关键分歧处向你发起结构化提问。
  - **写作**：可读取上下文并针对正文或设定提交修改建议，所有改动均经由「待审变更」确认后生效。
  - **审阅**：全只读视角，适合用于检查时间线、人物动机、因果逻辑与设定一致性。
- **透明可控的交互细节**：支持自由切换模型与思考强度（`reasoning_effort`），将单轮思考过程与工具调用摘要按时间轴折叠收纳；对话支持 `@` 引用指定章节或设定、发送中随时中止或中途插话、消息悬浮复制/回滚/新建分支（Fork），以及长对话上下文自动压缩。

### 5. 统一设置中心

点击左下角「设置」打开全高双栏设置中心，按职责清晰分为六个板块：

- **提供商**：管理各模型服务商的连接地址、鉴权方式与 API 密钥。
- **模型**：一键从提供商拉取或手动添加模型，支持单模型级协议覆盖（如同一聚合接口下分别走 Chat / Responses / Messages），并分别指定默认主写作模型与用于生成会话标题、压缩上下文的后台轻量模型。
- **写作规则**：分别编写全局写作规则与当前作品的专属单书规则，用纯 Markdown 约束文风、人称、禁忌或世界观硬规则。
- **写作模式**：查看各模式的工具边界，并直接编辑或一键恢复每种模式的系统提示词。
- **编辑与阅读**：自定义编辑区与预览区的字体、字号、行高与正文宽度。
- **数据与服务**：查看本机服务运行状态与数据目录位置，按需导出作品或创建、下载、管理全量本地 ZIP 备份。

## 快速开始

### 环境准备

- Python `3.14` 与 `uv`
- 若需从源码构建前端，还需 Node.js 与 `pnpm`（仓库已内置或构建产物位于 `frontend/dist` 时可直接启动后端访问）

### 1. 安装依赖并启动服务

在仓库根目录执行：

```powershell
uv sync --frozen
uv run python -m backend serve --host 127.0.0.1 --port 18082
```

当 `frontend/dist` 尚未构建或需要更新前端静态资源时，先在 `frontend/` 目录构建一次：

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm build
```

如需热重载开发前端，可在另一个终端运行 `pnpm dev`，开发代理会自动将 `/api` 请求转发到 `127.0.0.1:18082`。

### 2. 开始第一部作品

1. 浏览器打开 `http://127.0.0.1:18082`（接口文档位于 `/docs`，健康探针位于 `/health`）。
2. 点击左下角「设置 → 提供商」添加你的模型服务配置，再在「模型」中导入或添加可用模型并设为默认写作模型。
3. 回到书架点击「新建作品」或「导入作品」，即可开始创作。

> [!NOTE]
> 数据默认存储在仓库根目录下的 `data/` 文件夹中（包含 SQLite 数据库、加密密钥、附件、本地 ZIP 备份与运行日志），可通过环境变量 `INKWELL_DATA_DIR` 或启动参数 `--data-dir` 修改。服务默认仅监听本机回环地址 `127.0.0.1` 且不包含远程用户认证，请勿直接暴露到公网。

## 技术栈概览

- **后端**：Python 3.14 + FastAPI + 标准库 `sqlite3`（WAL 模式 + FTS5 全文检索）+ 自建 `httpx` 协议优先模型层 + 纯 Python `async` Agent Loop
- **前端**：TypeScript + React + REST + 单条全局原生 SSE（`EventSource`）
- **本机服务管理**：独立 `service/` 生命周期 CLI（`start` / `stop` / `restart` / `status`）与 `/health` 探针
